## Problem

Tableau dashboards supporting KPI tracking for 300+ stakeholders across Europe experienced frequent refresh failures — eroding trust in reporting and creating manual rework for the analytics team.

## Approach

- Redesigned ETL/ELT pipelines using Python, Pandas, SQLAlchemy, and SQL.
- Added validation checks at key transformation stages and bottleneck investigation workflows.
- Implemented monitoring and data quality controls aligned with Snowflake reporting layers.
- Partnered with development and QA on source-to-report reconciliation and discrepancy investigation.

## Stack

Snowflake · SQL · Python · Pandas · SQLAlchemy · Tableau · Tableau Server

## Outcome

**60% reduction in dashboard refresh failures** and increased reporting trust through systematic validation and coordinated fix verification with technical teams.
