## Problem

Summit Communications needed a centralized system to maintain technical and non-technical information for IIG (International Internet Gateway) downstream partners — replacing scattered spreadsheets and manual tracking.

## Approach

- Built a full-stack Django application with MySQL backend and Bootstrap UI.
- Designed forms for client info, technical data, and license tracking with search-as-you-type filtering.
- Added user authentication, activity logging, and Excel export for reporting workflows.

## Stack

Python · Django · MySQL · HTML · CSS · Bootstrap · JavaScript

## Outcome

A live production tool used by ~50 people daily. Nominated **Best Project** at the Q3 2020 townhall meeting.
