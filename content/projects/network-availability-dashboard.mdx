## Problem

A major telecom client needed a graphical view of historical network availability — with filterable time ranges and clear visual trends for operational review.

## Approach

- Elicited requirements directly with the client to define KPIs and view layouts.
- Built an interactive web dashboard using HTML, CSS, JavaScript, and Google Charts API.
- Designed multiple filtered views for drilling into availability patterns over time.

## Stack

HTML · CSS · JavaScript · Google Charts API

## Outcome

Delivered a client-facing dashboard for network availability monitoring. Development continued with iterative feedback; snapshots shown use representative data.
