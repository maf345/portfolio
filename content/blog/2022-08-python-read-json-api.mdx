## Introduction

Reading data from API (Application Programming Interface) is a common task in data analysis. When working with APIs, it is common to receive data in JSON (JavaScript Object Notation) format. JSON is a lightweight data interchange format which is easy for humans to read and write. It's also easily parsed and generated by machines. We will be using Python and it's libraries to read JSON data from APIs and convert them into tabular format after that.

## Import Libraries

We will start our work by importing all the necessary libraries first. If `requests` module is not already installed in your machine you can install it by running any of below commands - 

> `conda install requests` (if you are using anaconda distribution)  
> `pip install requests` (without anaconda distribution)

```python
import requests
import pandas as pd
from requests.auth import HTTPBasicAuth
```

## Read Data from API

There are some public APIs where data is accessible without any authentication. On the otherhand, data in business is mostly protected because of necessary privacy and security reasons. We will see how we can retrive data from APIs with/without authentication.

### API with Authentication

We've written a function below for getting API data which is protected by username and password. We are using python's `request` and `pandas` module in this purpose.

```python
def read_api_data_with_auth(url, username, password):

    data = []

    json_response = requests.get(url = url, auth = HTTPBasicAuth(username, password))

    for i in json_response.json():
        data.append(i)
    
    df = pd.DataFrame(data)

    print('Successfully read {0} rows from API: ({1})!'.format(df.shape[0], url))
    
    return df
```

#### Example API-1:

Calling the function by passing `API URL`, `username` and `password` as parameter. The function sends a call to the API and retrived all the 168 rows present there.


### API without Authentication

We've written a function below for getting data from public APIs. We are using python's `request` and `pandas` module in this purpose as well.

```python
def read_api_data(url):

    data = []

    json_response = requests.get(url = url)

    for i in json_response.json():
        data.append(i)
    
    df = pd.DataFrame(data)

    print('Successfully read {0} rows from API: ({1})!'.format(df.shape[0], url))
    
    return df
```

#### Example API-4:

Calling the function by passing `API URL` as the only parameter. The function sends a call to the API and retrived all the 4566 rows present there.

```python

```
